# 头发高光、眼层与发束明暗

头发与眼睛决定二次元角色的神采。这一份参考讲清眼影平面、高光小片、虹膜作者图、固定发影、单一受光高光遮罩、HM 发束明暗、可选头发 SDF，以及程序化发丝的研究路线。

## 1. 眼部阴影平面、瞳孔高光与虹膜图

眼睛发灰、死黑或层次不清，先拆开四层归因：虹膜底图、光照乘色、眼影平面与高光小片。

- **先查槽位与连通块**：读清原网格的材质槽与面片连通关系（部分原始资产里眼影面片或高光小片会暂挂在皮肤或虹膜槽上）。只需改目标面片的材质索引就能恢复独立材质，保留原坐标、UV、形态键与蒙皮权重。
- **创建受管眼层**：用 `toon-workflow surface-slot` 执行 `eye-create`（`settings.kind` 选 `SHADOW` 或 `GLINT`），后续用 `eye-read` 读取、`eye-update` 调整参数：
  - `SHADOW`：调节 `opacity` 与 `tint`，用 `BLENDED` 彩色乘法透射在眼白上方叠出柔和阴影（规避 `DITHERED` 退成灰度的问题）。
  - `GLINT`：调节 `opacity`、`glint_color`、`uv_name`、`center`、`radius`、`feather`，做出清晰可控的瞳孔高光小片。
- **保持深度一致与排除眼层源边**：受管眼层在联合渲染里按真实射线距离与二维线条排前后，眼线与睫毛不会被错误遮断；描边系统会在笔刷采样前自动排除眼层源边，保持干净边缘。
- **校准虹膜作者图**：关掉眼影平面后若虹膜主暗区仍在，问题就在虹膜图本身。更换虹膜图时保住瞳孔中心、外圈位置、真实 UV 与左右镜像，确认主高光归属贴图还是 `GLINT` 小片以避免叠出双高光；如果描边线色开启了 `UV_IMAGE` 绑定同一张虹膜图，同步更新两侧图像引用并重新打包冷重开。

## 2. 固定发影（B 通道正片叠底）

固定发影用来在发束缝隙和内层保住稳定的暗块，即使转灯也不会丢掉发型立体感。

- **接入与更新**：用 `toon-workflow surface-slot` 执行 `hair-shadow-attach`，传入 `hair_image`（已保存图像名）、`hair_uv_name` 与可选 `hair_strength`、`hair_tint`；用 `hair-shadow-read`、`hair-shadow-update`、`hair-shadow-remove` 维护参数，外部遮罩文件同步写进 `resources`。
- **色彩空间与叠加顺序**：固定发影接在动态色阶之后，按 `C_dynamic * (1 - strength * B * (1 - tint))` 正片叠底，使固定影与动态暗部重合处自然加深。沿用既有贴图时保持原图原本的色彩空间语义（例如既有 `sRGB` 蓝通道按原意读取，保持原始色彩空间设置）。
- **无损替换图像或 UV**：需要换新图或换 UV 层时，使用 `hair-shadow-replace` 原位更新 `hair_image` / `hair_uv_name`，完整保留既有 HM 明暗、月牙高光遮罩、外部连线以及当前强度和 `tint`。遇到亮缝过重时，先用分层消融对比「降低固定影对比」与「重绘贴图」，优先保住贴合发束的原有造型。

## 3. 单一受光高光遮罩（R）与防双亮带

让头发高光像手绘一样贴合发束弧度，同时随主光自然消长，核心是把遮罩和受光权重合二为一，只着色一次。

- **挂载遮罩**：先用 `surface-slot` 的 `hair-map-attach`（传入 `image_name`、`sun`、`uv_name`）建立 HM 受光链，再用 `hair-map-mask-attach` 绑定 `highlight_mask_image_name`、`highlight_mask_uv_name`、`mask_black_level`、`mask_white_level`；查询与卸载用 `hair-map-read`、`hair-map-mask-remove`、`hair-map-remove`。
- **单高光所有者纪律**：启用遮罩高光前，把同槽原有的 `finish-slot` 或 `HEAD_BAND` 高光归零，让新 R 覆盖图与半角/受光门控相乘后以同一高光色和色表只混色一次，再统一经过固定发影 B。这样暗面不会冒出漂浮假亮带，也不会出现两套亮带叠加或互相压暗。
- **黑白位实测标定**：生图或绘制出的黑色背景偶尔带 `1/255` 微弱底噪，先实测目标通道带外最大值，再设置准确的 `mask_black_level` 与 `mask_white_level`（例如带外最大 `1/255` 时将黑位设约 `0.004`），既保住原图字节，又让暗区彻底干净。
- **亮条先消融再动手**：头发背面或侧面出现意外亮条时，先在工作副本分别临时关掉 R 高光与 B 固定影看同机位对照。关掉 R 后亮条仍在、关掉 B 才消失的，根源在固定影暗纹之间的窄亮缝，应调固定影而不是堆高光遮盖。
- **前后发独立落点**：前后发各自建立独占 `Image` 引用与适配自身 UV 的月牙形状，后发亮度按参考适当收弱。每轮调整完高光位置，都在完整材质下从正面、斜侧、背面逐束复核：区分「发束在角色哪一侧」与「亮舌落在发束哪一边」，确保不跨发缝、不左右错位。

## 4. HM 逐发束明暗与法向混合

HM（Hair Map）把发束明暗偏移放进 G 通道，在单白 `Sun` 受光门控下平滑驱动发丝层次。

- **节点链与受光前提**：标准串联顺序为「原色阶 → HM → 固定发影 B → Emission → 外部修饰」，HM 总强度归零时完整旁路。首片受光门控面向 EEVEE 单可见白 `Sun`、零环境光 World 的场景；修改 `Sun` 能量前，先 `hair-map-remove` 卸载 HM，改完能量再重新挂载。
- **G 通道作者图要点**：G 是围绕中性值的明暗偏移数据，空白背景区保持中性灰而非纯黑。更换后发占位图为真实发束 G 图时，按「卸载遮罩 → 重绑 HM → 接回遮罩」顺序操作；由于 G 会改变亮暗基准，换完 G 后即使高光图未动，也需重看完整材质确认高光范围。
- **影界碎块排查**：关掉 R、G 偏移后发束上仍有碎影块，先对比当前混合法向与纯艺术法向响应。头发网格本身起伏过碎时，查清各部件原始权重覆盖率再调整艺术法向混合强度；不同发片（如前发与长后发）分开定强度。

## 5. 可选头发 SDF：`sdf-hair`

大多数二次元发型用法向 + 固定发影 + 单一受光高光就能稳定出片；当特定发型需要随主光大角度改变发束自身影形时，再评估 `toon-workflow sdf-hair`。

- **命令操作**：用 `sdf-hair` 执行 `compile`（根据锁定计划编译打包 EXR 图集）、`stage`、`attach`（初始零强度挂入）、`read`、`update`（调整 `strength` 与 `softness`）与 `remove`（恢复原 HM 图）。
- **模式选择**：`cyclic_v1` 覆盖八个水平方位角，适合以水平转灯为主的镜头；`omni_v2` 额外纳入上下仰角与独立顶/底键（三张图集 `atlas0_name`、`atlas1_name`、`pole_atlas_name`），避免纯顶底光突变。
- **UV 与距离尺度检查**：进入编译前先核对真实发束 UV 是否有重叠或过低像素密度，并统一共同的模型空间距离尺度，避免空岛大常量压过真实短距离造成整块横切帽带。检查时把完整长后发收进取景框，头肩裁切之外的发梢同样要过目。

## 6. 程序化发丝、各向异性高光与刘海眼透（候选研究方向）

遇到「顺发丝细微色差」「随视角滑动的 Kajiya-Kay 横向亮带」或「透过刘海隐约透出眼睛」等进阶需求时，先用下表选最省力的成熟路径，有明确画面收益再做节点小样对照：

| 画面需求 | 优先落地方案 | 进阶小样要点 |
|---|---|---|
| 高光跨束、暗面漏亮或形状不合参考 | 先修现有 R 遮罩、UV 落点与受光门控 | 保留既有材质骨架直接修正 |
| 顺发束细微明暗与色差 | 建专用流向 UV（保护原颜色/R/B UV）加程序化条纹细节 | 先用方向色验证根梢与镜像手性，保留整头艺术法向大形 |
| 随视角与光向滑动的发丝亮带 | 先试 `HEAD_BAND` 或 HM 遮罩高光 | 做 Kajiya-Kay 小样时定义稳定切向（头级轴或显式 UV flow），保持单一主高光所有者，有符号点积做连续三色过渡 |
| 透过刘海读到眼睛 | 独立 View Layer / 遮挡遮罩交合成部门叠合 | 用含双眼、刘海与外部遮挡物的最小样例验证，只对指定刘海生效并核对眼线与预乘 Alpha |
