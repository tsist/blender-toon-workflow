# 三渲二商业验收

验收单位是具体镜头或独立资产。开工先写明目标等级、风格参考、使用机位、光向和帧域、引擎、分辨率、通道配置与预算。镜头和独立道具各出一份 `quality-scorecard.json`。共享 Wiki 的分层框架用于追溯技术与风格依据。 [Wiki 原文](<<MEMORY_STORE>/wiki/concepts/toon-commercial-acceptance-layered-framework.md>)

## 审片取证

| 对照 | 固定条件与要查的问题 |
|---|---|
| 风格基准 | 同一持物半身机位、姿态、握位和灯光。按定稿参考分别看脸颈大影、鼻颊细影、眼白与虹膜、发束暗层和光带、布料宽亮面、硬件窄高光、冷暖和线色。三风格项目用同一角色并排三版，每版记录目标、差距和裁切位置。 |
| 主辅光和转头 | 同机位分别做只转头、只移主光、只开关副光。记录实际求值头轴和灯向。配对保留 `Beauty` 与主形体诊断。角色主影由主光专管时，副光要有可见响应，主影分类应保持。真实发影和颈部投影另查。 |
| 环绕与极端光向 | 固定姿态做相机环绕，另做固定机位的主光扫描。检查前侧、斜上斜下、纯顶底和跨背缝。复核 `90°/35°`、`90°/60°` 的正负组合及 `−135°/85°` 的邻角。发现眼下横带、颊影尖折或孤岛时，用交付分辨率补邻角。记录画面左右与有符号头轴。 |
| 连续短段 | 完整播放覆盖转头、起持、遮挡、显露和收回的短段。逐帧查轮廓、鼻嘴短线、指节、发丝、袖口和道具接触。分开记录静止区变化、返程同姿态差和真实运动变化，附原尺寸帧或连段。 |
| 迁移 | 在第二个角色上显式重绑材质槽、真实 UV、遮罩和头轴，记录校色项。在同一配方的室内和室外各保留基线和适配图。记录实际人工步骤与用时，单独填作业墙钟时间和峰值资源。 |
| 独立冷开与恢复 | 退出本次工作进程后，另起进程冷开同一稿件。核对源、贴图、链接库与受管状态，复渲代表帧并按交付配置重组。恢复批次记录来源、复用帧、补帧、媒体指纹与父作业终态。 |

对照锁定相机、姿态、色彩管理、分辨率、采样和时间编号。像素测量注明区域、阈值、位深与容差，标出实际需要修的帧、光向或部件。按正常观看尺寸判断画面，并以 1:1 裁切定位短线和影边。像素指标用于佐证具体观察。

## G1–G5 计分

| 梯度 | 满分 | 验收依据 |
|---|---:|---|
| G1 工程 | 15 | 冷开、外链闭包、可迁移路径、变换、数据贴图 Non-Color、渲染开关及源保护。记录宿主构建、插件实现和源 SHA。 |
| G2 结构 | 25 | 核对米制、正面朝 -Y、落地原点、应用缩放、单根、语义命名、可见控制笼与实际渲染拓扑。对辅助件记用途与实际可见性。 |
| G3 参考 | 25 | 审查轮廓与比例、参考风格、脸颈影形、眼发层次、衣料与硬质材质、色彩冷暖。用可比基准图和备注说明取舍。 |
| G4 光影与时序 | 20 | 审查转头、逐灯、环绕、变形和握持在连续帧中的表现。查描边跳闪、遮挡穿帮、影区突然翻转和高光漂移。 |
| G5 交付品相 | 15 | 镜头按约定通道、色彩空间、预乘和重组验收。可复用资产按 UV、纹素、PBR 与双引擎验收。记录独立资产的贴图或原生材质重建范围。 |

### G1 / G2 红线

- **G1**。另进程冷开，贴图打包或走 `//` 相对路径，外链和使用中的材质槽全部可解。无负缩放、非有限坐标和断链驱动。数据贴图为 Non-Color，切刀关闭渲染，视口与渲染细分级一致。
- **G2**。核对米制与轴向、落地原点、静态网格缩放 `1,1,1`、单一根集合、语义命名及零引用孤立数据。核查实际渲染笼的退化面、非设计性重复共面、细分或变形网格 N-gon 与曲面六价及以上极点。带护边的静态平面封口按项目建模规则评定，豁免须记录对象、位置与用途。 [项目建模红线](https://github.com/tsist/blender-modeling-review/blob/main/SKILL.md)

在模板的 `hard_gate_checks` 中逐组记录状态和证据，并按目标等级汇总 `hard_gates_passed`。

### 放行

- L1 要求 G1 全过、总分至少 65。L2 要求 G1/G2 红线全过、总分至少 80、各适用梯度至少 70%，由独立只读审核签认。L3 要求红线全过、总分至少 90、G2/G3/G4 各至少 85%，同样需要独审。
- 使用 [JSON 模板](../assets/quality-scorecard.template.json)，填实际得分、核查状态和证据。每项核查用 `pass`、`fail`、`not_run` 或 `not_applicable`。必要项未跑时保持待验。仅交白模等明确范围按适用分母折算，并在 `review_scope` 说明。已列为交付要求的工序需完成后才能放行。
- 记录实际引擎及分支范围。Blender 5.3 的 EEVEE 逐灯镜头交付按已声明的引擎评定。合约要求 Cycles 时另交同工况证据。普通不透明相关采样交 `BeautyLineInteraction`，原生媒体艺术线交 `OpticalLine`，各自按合成合同冷读和重组。 [合成合同](cli-ops-and-handoff.md#5-与合成部门的线色叠合交接合同)

## 5.3 签认样例

- **Snow 持原创录音麦**。固定机位 EEVEE 第 1–9 帧，800×800，L2 85/100。现场保存稿的分层、主副光及代表帧独立冷开有据。发暗层与衣暗部较近，眼白偏亮，个别短线仍有细像素瑕疵。 [镜头评分](<work/audit/<batch>/>)
- **原创录音麦 v3**。独立资产 L2 87/100，有 UV 棋盘、EEVEE 光追和 Cycles 的证据，纯贴图重建缺证已扣分。 [道具评分](<work/audit/<batch>/>)
- **爱音与雨果**。爱音三版各有同条件目标帧，冻结的面影和动作保留。雨果覆盖现场回退、环绕与室内外迁移。各自以已取证的光向、帧和许可范围引用。 [三风格对照](<work/audit/<batch>/>) · [真实制作证据](<work/audit/<batch>/>) · [教程库](<<PROJECT_ROOT>/tutorial-library/_INDEX.md>)
