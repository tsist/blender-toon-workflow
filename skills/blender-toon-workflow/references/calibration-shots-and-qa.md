# 参考校准、镜头修形、环绕检查与排错闭环

把三渲二做到经得起特写与转镜考验，靠的是四件硬功夫：参考校准有章法、UV 落点先验证、镜头修形不反噬、遇到问题按闭环分层排查。

## 1. 参考驱动的风格校准

开工前先把参考图分类，把「角色固有设计」和「具体镜头的氛围光色」拆开记录：

| 参考类型 | 用来定什么 | 落地时的注意点 |
|---|---|---|
| 已上色公式立绘 | 基础色、基本影色、深影主次与关键线色方向 | 扫描与压缩会偏移 RGB，先核对色相与明度层级，再转线性写入 |
| 设定线稿与表情小图 | 对应表情的鼻嘴短线、结构线角色与信息密度 | 选与当前模型表情可比的样例，保留模型既有姿态 |
| 动画剧照 | 镜头光色、逆光/夜景识别度与高光强弱 | 场景氛围偏色归入镜头灯光与合成，保持基础色表干净 |

- **固定可复用配方**：校准完成后，分门别类记录基色/影色/线色、贴图真实 UV 与通道语义、主光与曝光覆盖以及输入专用选区。换新角色或新机位时，先在零影响或中性状态下核对配准，再按新参考逐项调整。
- **区分抗锯齿混色与真实墨色**：从参考图取样线色时留意边缘抗锯齿和透明混合，全量套入偏浅取样色容易在暗部丢失轮廓对比；保持线宽与 Alpha 稳定后，分别在正常展示尺寸下核对皮肤、头发、睫毛与衣料线色。

## 2. 定位贴图与遮罩的 UV 适配五步法

凡是要求落在精准表面位置的贴图（面部 SDF、头发月牙高光、固定发影、眼层遮罩），按以下五步先配准再调光：

1. **查清真实消费链**：记录对象、已用材质槽、`Image` ID、通道与色彩空间、显式 `ShaderNodeUVMap` 节点、映射缩放偏移及扩展方式，以节点显式指定的 UV 层为准。
2. **建立 UV 到表面的对应**：导出目标网格当前 UV，用编号、棋盘格或眉间/鼻尖/发束锚点标清根梢、左右、镜像与 V 轴方向，并核对细分或镜头修形后的 `RENDER` 求值差异。若原有 UV 重叠导致目标区域缺乏独立控制，保留原 UV 并在安全范围内新建专用 UV 层。
3. **按对应关系制作候选图**：把弧度、断口、渐隐与安全黑边落在目标 UV 岛内；在原生网格或已核机位绘制后烘焙到 UV 时，检查可见面防穿透背层或镜像串扰。原 UV 贴边时预留微量黑色余量，防止细分插值越界。
4. **先无遮光查落点，再恢复完整材质查光照**：先在临时副本用自发光/无遮光模式查跨岛、跨束、接缝与镜像问题；确认落点准确后恢复完整材质，在正面、斜侧与背面实渲核对受光权重与固定发影叠底。每轮改完落点都看新完整材质渲染，逐束区分「发束在物体哪一侧」与「高光在发束哪一边」。
5. **留存可复核配准记录**：记清「目标亮形/影形 → 表面锚点 → 物体侧与束内偏向 → 已看机位 → 采用或否决理由」，更换网格、UV 或修改器后只复核受影响项。

| 异常现象 | 优先排查环节 |
|---|---|
| 关掉全部高光后仍有亮条 | 原底色、固定发影 B 与动态明暗块面 |
| 无遮光诊断里遮罩已经跨束或串到背层 | 实际 UV 到表面对应、共享岛、可见性与投影域 |
| 诊断落点正确，完整材质里才跑偏 | 真实主光方向、视向、受光门控与高光响应 |
| 画面出现双亮带或一亮一暗互相抵消 | 旧 `finish`、HM 与遮罩高光的权重合并，保持单次着色 |
| Beauty 正常但最终脸线或发束线异常 | 正式 `Line` 通道与联合求值，排查线组与局部减线 |

## 3. 逐镜头修形方案：`camera_shots`

三渲二特写或斜侧镜偶尔需要微调透视比例，按机位挂受管镜头修形，保持原网格拓扑与默认机位不受干扰。

- **编辑与预览**：在工作副本为目标网格配置受管几何节点修形器与 `[0, 1]` 顶点权重（默认强度 0），再用 `viewport-lines` 的 `inspect-workbench-correction` 与 `edit-workbench-correction`（支持 `ZERO_WEIGHT`、`CREATE`、`CONFIGURE`、`DEFINE_SHOT`、`SHOT_STRENGTH`、`APPLY_SHOT`）按 `Scene` 相机保存逐镜头修形方案。所有镜头保持同一组 `targets` 身份，后台渲染时按当帧真实渲染相机自动套用对应方案，并在联合报告中写出 `camera_shot` 回执。
- **避免附属件二次变形**：像虎牙、眼饰这类通过 `Child Of` 跟随主体的零件，将约束参考指向一份共享原网格与形态键、但未挂修形的动态参考体，让零件跟随角色变形的同时只接受一次镜头修形。
- **有修形时的跨机位核对**：不同相机应用不同修形强度时，求值网格坐标合法地随相机变化；核对材质与 UV 保护时，按每个机位与自身原版分别比对。

## 4. 环绕光照与多机位批量检查：`omni-preview`

调完面部 SDF、头部法向或头发高光后，跑一轮多角度环绕图集，把单帧藏住的翻车角度一次揪出来。

- **命令操作**：用 `toon-workflow omni-preview` 执行 `read`、`plan`、`submit`（传入新的 `--output` 作业目录）、`status`、`cancel` 与 `select-page`（传入 1-based `page_index`）。
- **网格规划与看图重点**：先用 9 格或 16 格排查大形与主要偏角，再用 36 格或 64 格分页覆盖上下斜光与极点邻域，纯顶底极点去除重复方位角；发现细节疑点时回到目标分辨率单帧实渲。逐格盯紧顶冠/发梢随仰角变化、极点附近有无突变、月牙高光是否在暗面漏出以及眼鼻颊嘴的可读性。
- **临时转灯后及时复位**：诊断时临时旋转 `Sun` 后，恢复原始位置、缩放、旋转模式（`Euler`/`Quaternion`/`AxisAngle`）与 delta 通道，再验证求值矩阵还原。环绕预览聚焦材质与受光诊断，最终轮廓线质量仍看正式 `Combined` 与白底 `Line`。

## 5. 连续帧穿线防抖检查与六步修正闭环

有转头、运镜或遮挡变化的镜头，单帧过关后再抽一小段连续帧（如 6–12 帧）跑正式联合渲染，确认以下四项稳定再放行：
- 轮廓线与五官短线在连续帧间平滑移动，无高频闪烁或突然断链。
- 发束与脸颊交界、眼影与睫毛前后关系正确，线条无穿进五官或错误透底。
- 面部 SDF 影界与高光随转头或转光连贯过渡，无孤立亮岛或快扫跳块。
- 若场景依赖头发布料等未烘焙动态，对比直接跳帧与顺序播放结果是否一致，必要时先退回上游烘焙缓存。

遇到「画面与参考不符」「线消失或太重」「新角色套用出错」时，按下面六步修正闭环快速收口：

1. **定清画面目标与基线**：选可比参考，在正常展示尺寸写明鼻影、五官线、眼部主次与发束块面的目标效果；锁定已确认的工作副本与 SHA256。
2. **单变量分层消融**：固定机位、姿态、主光与采样，对照 `Combined`、`Beauty` 与白底 `Line`，逐项旁路 SDF、接受层、眼层、固定发影或高光，精准归因到单一层。
3. **屏幕疑点落回真实部件**：用原网格索引做作者写入，用 `RENDER` 求值三角、支持面与角点索引解释屏幕像素，核实空间前后关系，防止误改背面或共享材质。
4. **做最小可编辑增量**：材质与独立 Line 分开修改，经由原作者接口更新受管节点，避免为着色问题强拆网格或移动零件。
5. **按影响面三维度验收**：分别核对原数据保护（含获准例外）、冷重开与同帧 `Beauty`/`Line` 一致性、以及正常尺寸的视觉可读性与连续帧稳定性。
6. **沉淀结论与恢复入口**：记录采用的作者文件、依赖路径、已看机位/光角范围与待跟进项，保留原源与关键前后对照图供随时回退。
