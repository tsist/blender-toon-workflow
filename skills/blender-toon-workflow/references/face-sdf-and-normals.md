# 面部 SDF、头部法向与上下光检查

面部大块明暗交给专用 SDF 入影图，局部转折交给艺术法向，鼻唇轮廓线交给二维描边。按这三层各司其职，调一个地方才不会把别处带歪。

## 1. 面部 SDF 搭建与方向模式：`sdf-face`

已有合法 SDF 读者先只读 `inspect` 复用，改动线条或色表时保持原 SDF 链不动；首次建立或切换方向模式时按以下顺序操作。

1. **枚举全部消费槽**：先按真实 `Material` 身份查清使用该皮肤材质的所有槽位与面域（脸颊与下颌可能分占不同槽），对独立材质只执行一次绑定并核对全部消费槽。
2. **建前投 UV 与方向载体**：用 `toon-workflow sdf-face` 依次执行 `create-front-uv` 与 `create-carrier`，再调用 `bind-reader` 绑定显式 `Non-Color` 贴图（本地 `FILE` 或 `PACKED`）、`Linear` 过滤与 `EXTEND` 边界。确认右向镜像（`U = 1 - U`）与实际 UV 对称性一致，并确保 `ShaderNodeUVMap` 显式指向目标 UV 层。
3. **选对方向模式**：用 `switch-direction` 按打光需求选择：
   - `AZIMUTH`：水平方位光角模式，入影相位为水平光角绝对值除以 π，适合常规水平侧光。
   - `POLAR_LRUD`：三维极角上下左右模式，传入 `vertical_image` 与 `vertical_uv_map`，响应真实三维主光仰角。
   - `DIRECTION_KEYS`、`DIRECTION_CONTINUITY`、`DIRECTION_AUTHORED`：高阶三维方向模式，额外提供 `direction_image` / `direction_uv_map`；启用连续性或定向修正时再配齐 `pair_image`、`pair_uv_map` 与 `pair_filter_radius_texels`。
4. **保旧层、建新层**：原水平左右图 UV 存在重叠时，保留原水平图与 UV，为新增的上下或高阶方向域新建独立 `Image` 与专用 UV 层，并用独立贴图验证消费域内无冲突。
5. **切换主光与解绑**：用 `set-sdf-light` 指定场景内已保存的 `Sun` 对象；更换方向图或调整绑定快照参数（如 `Softness`、影色）时，按「先移除艺术投影接受层 → `unbind-reader` → 重新 `bind-reader` → 重建接受层」的顺序操作，再用 `retire-unused-readers` 清理已退役读者。

## 2. 关键光角编译与阈值图平滑

单靠手绘整张灰图很难同时稳住前光、斜侧光与背光的入影时机；把形状设计和数值编译拆开更省力。

- **关键光角编译（`compile-keys`）**：先沿真实消费 UV 与镜像锚点（眉间、鼻尖、眼角、嘴缝、下颌）画出代表光角的二值明暗关键图，并在模型上检查落点。随后调用 `sdf-face` 的 `compile-keys` 生成独立目录与高精度 `PNG16` 贴图，确认各关键角在模型和编码回读里无嵌套矛盾后，再显式绑定到对应材质。
- **收窄硬边与空间平滑**：落点和形状已正确、只差影界过软时，优先收窄 `Softness`（以 `phase ± Softness` 做平滑步进）。若硬边暴露 8-bit 灰图的细微锯齿或亮岛，先在诊断副本把采样标量替换成单调 UV 场确认问题来自阈值图噪声，再启用采样平滑像素半径（3×3 空间过滤，先镜像后偏移）。切换采样半径或模式时，先用 `copy-image` 建立独立贴图副本，让每个材质读者独占自己的 `Image` 引用，保留源文件不被覆盖。
- **阈值顶点属性（`threshold-*`）**：维护旧式或局部顶点阈值场时，使用 `threshold-init`、`threshold-create`、`threshold-configure`、`threshold-write`（按 `LEFT` / `RIGHT` / `WEIGHT` 写明顶点索引、数值与混合）、`threshold-bind`、`threshold-unbind` 与 `threshold-read`。写完覆盖权重后用实际渲染核对脸、颈与嘴角的有效 `mix × valid`。

## 3. 艺术投影接受层与鼻影面片

单主光下刘海或五官在平涂皮肤上投出杂乱硬影时，用受管接受层控制投影去留。

- **绑定与参数**：用 `sdf-face` 的 `stage-cast-art`、`bind-cast-art`、`update-cast-art`、`inspect-cast-art`、`unbind-cast-art` 管理接受层。接受图保持 `Non-Color` 并显式选定 `channel`（R/G/B），白区保留原上游明暗，黑区按 `strength` 混向 `lit_color`（默认强度 0，黑白位 `0/1`）。额头若要留住刘海投影，确保额头区域在图上采到白色；同时观察黑区对接触影和皮肤纹理的影响。
- **强度关键帧动画**：新增接受层时开启 `animate_strength`，即可用 `key-cast-art-strength` 在目标帧（含可选子帧）打 `LINEAR` 强度关键帧。移除或换图前先调用 `clear-cast-art-animation` 解除曲线并保留旧 Action，再执行 `unbind-cast-art`。
- **鼻影独立面片**：角色鼻尖带独立面片时，先查真实连通块与材质索引，把该面片切到独占材质槽，再用独立 `Image` 引用单独绑定同一面部载体的 SDF，保留皮肤主槽不受干扰。同对象多材质读者共享面部载体与 UV，但材质槽与贴图引用各自独立；如需同时清掉鼻影面片多余边线，只写该面片角点的局部 R 通道。

## 4. 整头法向与局部顶点法向：`surface-slot --normal`

法向用来修饰眉、睫、发、颈与附属物的受光体积，和面部 SDF 互补配合。

- **分件配置**：运行 `toon-workflow surface-slot --normal`，用 `normal-settings` 调整部件参考方向、混合权重与强度，新加入成员默认从零强度起步，逐步加到轮廓干净为止。脸和身体共用一个网格时，把作用范围严格限定在头部顶点群，颈部出现异常亮斑时在局部给艺术着色法向，保持面部 SDF 不动。
- **逐顶点精修与对比**：用 `normal-write-direction` 和 `normal-write-weight` 对明确列出的原始顶点索引写入方向和权重，再用 `normal-render` 输出同机位前后对照图。不同发网格的局部权重覆盖率各自不同，先读实际求值 `mix / valid` 再定强度，保留原有自定义角点法向与网格几何法向原样不动。

## 5. 上下光、极点与连续影界排查

转灯出现影界突跳、眼下横带或鼻颊尖块时，按下面步骤做有区分力的归因。

1. **先读真实头部坐标系与主光方向**：读取头部实际 `right / forward / up` 轴与 `Sun` 世界 `+Z`，记录真实求值矩阵（四元数模式下直接改 Euler 不会生效，已有灯光 Action 也会覆写旋转；先看真实求值再出图）。
2. **四态消融定位源头**：固定机位、姿态与曝光，同条件看四张图——完整输出、旁路 SDF 的上游输出、旁路艺术投影接受层的输出、关闭主光投影的对照。再检查 `shadow × mix × valid` 因子与覆盖场，一眼就能分清毛病出在上游投影、SDF 阈值图、覆盖缺口还是接受层边界。
3. **配准画布与分拆局部细影**：复用既有二值稿时，连同原规范相机、求值表面与消费三角一起回投到当前目标 UV；若主影界与鼻唇细影在距离混合中挤出圆钝团块，将主影界与局部细影分别运输，并以真实 0.5° 细步邻帧排查快扫跳变，保持清晰赛璐璐边缘而非靠大幅调高 `Softness` 糊过去。
4. **同步检查线色节点耦合**：解绑或重绑面部 SDF / 接受层后，顺手核对绑定了 `NODE_RGBA` 的描边线色策略，把引用显式迁到新的目标节点插槽并核对 RGB 一致。
5. **只读采样已有姿态与表情**：借用工程里已有的转头、闭眼、口型帧来检验着色和影形时，先读实际 `driver`、曲线与 `RENDER` 求值形体（例如形态键 `0.5` 与视觉半闭眼需结合实图判断），在工作副本里保护原 `Action`、`slot`、`NLA`、骨骼与 `Shape Keys` 完整无损；若上游绑定或表情本身存在穿插问题，先记录为上游输入问题，选干净帧继续风格化工作。
