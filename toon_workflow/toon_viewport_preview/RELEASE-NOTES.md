# 0.2.27 本地发行说明

本版补齐逐视口显示设置的保存定位并集中整理发行材料。新增viewport_scope.py和add-on入口门控／UI／生命周期；绘线数学、作者、参数动画与输出消费者保持0.2.26的代码，不增加性能改造。

- 完整来源声明、GPL许可正文、适用NOTICE和SPDX文件清单随包保留；本地源码副本的实际修改单独列出。
- 使用当前Blender自身运行预览和后台输出，不附带商业Render App、专有pyd、用户角色或纹理资源。
- 安装、独立新输入、保存冷开、卸载与0.2.26回退的实际结果由外部第6阶段交付报告记录；包内说明不是运行成功回执。
- 继承0.2.26的类型参数动画、普通正交视口修复及有界参数菜单。PLD已按用户决定取消；EPS/AIEPS保留既有格式损失说明。
- “此视口显示描边”按Screen保存每个Space的开关；保存时记录实际area/space位置，重开恢复，失效目标与重复目标不会套用到另一个视口。

完整角色的48动作帧、48相机慢移帧和保留镜头仍绑定其原冻结输入与实际消费者证据。小型独立示例不替代角色时序资格，不证明商业原版逐像素或笔触语义等价。原手部保留镜头裁切限制、源rig的原有缺失引用和驱动警告保留。

复杂角色绘线仍可能等待较久。参数菜单的枚举收益不代表整个窗口快速；实测环境、输入与等待范围见第5阶段报告。最终用户对画面与动态效果的认可单独记录。
