# 二维描边 · 自动视口预览 0.2.27

Blender 5.2 的独立二维线条插件。已验环境为 Blender 5.2.1 LTS；线条在屏幕中绘制，无须生成三维线载体。来源、作者、笔刷、文件和输出功能使用同一套可保存样式；0.2.26增加独立的类型参数动画，0.2.27补齐逐视口显示设置的保存恢复并整理最终发行材料，绘线算法保持0.2.26的实现。具体安装、独立输入与验收范围以随交付报告为准。

## 开始使用

在 Blender 偏好设置中从磁盘安装本包并启用，在3D视口按 N 打开“二维描边”。“基础模式”可直接画轮廓、开放边、标记边、材质边界、法线角和原始边线框。“自主作者 · 文件与范围”中选择网格，点击“从零新建并绑定选中网格”，即可建立独立样式；已有自主 JSON 样式可替换载入或追加。

开启自动预览后，调整参数会自动更新。旋转、平移、缩放或移动物体时显示原视图，停止后加载新线条。支持叠加、仅描边、白底及自定义背景。主图和相机／渲染输出沿用实际作者数据；输出到新的绝对路径，同名文件不会静默覆盖。

“此视口显示描边”可单独关闭当前视口的线条，其他视口继续显示；场景的“自动描边”仍是总开关。每个屏幕布局的视口开关随`.blend`保存恢复，布局中已经离开的视口不会把旧设置套用到另一个视口。后台渲染与后台序列继续沿用场景作者，不受此显示开关影响；视口导出与依靠视口快照的相机输出需要相应视口开启。

普通正交视口支持跨过视原点的有符号近远裁切范围；相机与透视投影继续使用各自的有效范围。新参数面板按当前类型与作者列出数值字段，单次枚举复用已解析记录。同一已编译样式保留有界菜单项和字符串引用；样式、修订、类型或作者变化后失效。

## 作者与来源

每组可绑定对象、集合及其子集合或材质。批量编辑可筛选名称／库路径，并全选、反选、全不选；空选择表示不绘制。数据块重命名或搬库后，可显式修复失效引用，不按相似名称猜配。

独立组有自己的可见线 V、隐藏线 H 默认笔刷；首次使用某类专用笔刷时建立独立作者。八类来源为轮廓／开放边、Object 对象内线、真实三角求交、平滑边界、材质边界、标记边、法线夹角和原始边线框。类别可重叠，保留类别标记；同实际笔刷同通道按最大 Alpha 绘制。Object 是轮廓父边上的分类区间，支持正交／透视和近远裁剪，不等于绘制所有内边。

“Line层级与集合合并”控制多个 Line 的独立所有权、优先级、空输入槽、连接、排序、收起空槽及逐 Line 输出选项。集合可声明合并域，组的 V/H 轮廓合并开关独立。禁用保留作者；“移除组并保留恢复”从活动来源中移除组，使剩余组重新取得所有权。最多32组，含可恢复项，至少保留一个活动组。

“新作者图”从当前最新文档建立原生 NodeTree，Line／LineSet／Brush 及 Reroute 的连接在点击“应用图”后参与绘线。过期图会拒绝覆盖较新的文档。作者“编辑频道”切换 V/H 控件和笔刷编辑入口；另一频道笔刷节点折叠，已连接插槽按 Blender 规则保留显示，连接及两通道渲染开关不变。跨 actual 连接复制到拥有独立身份的目标作者，保留目标身份。

## 笔刷与线条功能

笔刷提供 SIMPLE、NORMAL、MULTIPLE，形状／拉伸／角度／凹槽、随机、复制、偏移、延伸、扭曲、颜色、纹理与贴图坐标、宽度和 Alpha 曲线、距离衰减、尺寸与像素比例、屏外距离、抗锯齿和过采样。链参数处理连接、分割、方向、闭环、最短链、weld／seam，虚线沿完整父边弧长求值，裁切和遮挡不重启相位。数值与随机规则为自主定义，不声明与商业原版逐像素等价。

材质属性的“自研材质线条功能”可按实际对象／材质目标提升隐藏线、遮罩、调整颜色／宽度／透明度、禁用交线；每通道自交、组遮罩以及对象／集合／父级 holdout 进入同一绘线流程。无效目标、空规则及仅颜色规则保持原有可见性分类。

## 参数动画

在笔刷、Line、合并开关或材质线条功能旁点击关键帧入口，再打开侧栏“新参数动画”。选择参数及向量分量，点击“取当前值”，填写待写值后用“插入/更新”写入当前帧。可删除当前帧键，或停用动画恢复静态作者值；键和轨仍保留。整体线宽与既有按actual影响量动画继续使用各自入口。

支持笔刷效果中的数值、开关、贴图偏移/平铺分量、显式焊接开关，Line优先级/抗锯齿等数值，以及合并、材质覆盖、遮罩和自交开关。浮点按LINEAR插值，整数与布尔按CONSTANT保持前键；整数键须能由Blender FCurve精确表示。参数值进入视口、相机、后台逐帧输出、笔刷预览和矢量输出，原静态JSON不会被逐帧改写。

原基础笔刷尺寸/颜色/Blend、资源与对象引用、枚举、曲线点集合和None继承状态保留为静态作者。新参数轨使用本地可编辑Scene/Action的单层KEYFRAME及当前SCENE slot；不支持新轨上的Bezier、NLA、driver、modifier、sampled或mute曲线，遇到不支持状态明确拒绝。停用全部新参数轨可恢复静态效果；源对象/骨骼的驱动与Scene动画轨分别处理。

删除或更换启用轨的作者会被拒绝；归档其最后活动所属组前须先停用相关轨。标签改名和集合重排不会重新绑定身份。作者图上的草稿关键帧仍需显式应用成静态作者；绘线动画使用上述参数轨。保存`.blend`会保留真实Action、slot和关键帧，样式JSON只导出静态作者与控制表。

## 文件、辅助与输出

完整样式 JSON 可导入、导出、追加，并保留引用、作者及各控制表。captured 作者追加时转为独立拥有的作者，原来源以非执行归档保留。提供19个自主笔刷预设、GPU笔刷／笔触 PNG 缩略图、工作区和可编辑的 Selection Shape Geometry Nodes 辅助；详细命令入口见包内 author_cli.py。

PNG、线性 OpenEXR、多层 COLOR／Depth、相机／渲染及序列输出沿提交时的场景快照执行。Depth 使用相机轴向深度，近白远黑并保留线条 Alpha。分层元素可按类别、V/H、数字线集合 ID、样式组筛选并设置背景；不能反向开启已关闭的来源。支持指定 Scene／ViewLayer 范围、仅关键帧和作业超时。取消只停止所选作业，已发布完整文件保留；目前没有中断续算。

“Vector File Output”输出 EPS 或 AI(EPS)，可增删排序输出项、筛选来源／通道／数字ID并选择显式分组。3D视口面板使用当前 ViewLayer 的独立输出设置；合成节点编辑器选中本地 Image 节点后，在同侧栏的“Image Node Vector Output”管理该节点的独立设置。切换层或节点不会覆盖另一目标；指定层实际使用其依赖图。开发接口保留 Scene legacy 默认，可显式传 view_layer 或 node_ptr；节点 UUID token 可保存冷重开，十进制地址仅限当前会话，未知／过期地址明确拒绝。

矢量默认保留生产绘线的逐 Line、H 后 V 次序，启用链与虚线时使用生产相位流程。EPS 写出真实填充路径和颜色，AI(EPS)添加图层信息；读取器已验范围和使用限制写入每份报告。格式不保留逐笔 Alpha、纹理笔尖、光栅抗锯齿或原生 stamp 轮廓，颜色渐变降为段平均色，遮挡沿中心线采样。需要保真图像时使用 PNG／EXR。用户已取消 PLD 格式要求，界面不再提供 PLD。Adobe Illustrator 实际图层导入和印刷／ICC流程未验，不声明商业原版兼容等价。

阶段4包含真实操作器、作者到绘线、多层元素、独立保存冷开、原生作者图和代表性鼠标交互。完整原角色保留8网格／147168三角形：旧默认输出对0.2.24逐像素一致；新来源＋NORMAL纹理＋材质线条功能的 RENDER／CAMERA／COLOR／Depth 在冷重开后逐像素一致。此范围为静态功能集成，未代签原版等价、全部属性鼠标覆盖或用户最终视觉认可。

完整96冻结输入、三校准／三保留镜头、新参数动画、时序与实际等待的验收范围和结果见阶段5报告。96输入为48个角色求值快照与48个面部相机慢移，FHD24；它们不等于重新求值或修复源rig。性能工作在动态功能之后集中进行，报告中的秒数只描述本机输入。源角色既有驱动／缺失库问题保留；一个历史缺失库路径在 Blender 重开时减少一个重复计数，唯一依赖与 missing 集合及 drivers 保持。Object 采用实心双面模型，未把任意透明材质／原版 culling 规则当作已支持；近退化不可表示的正区间仍明确拒绝。最终独立发行、权利材料与用户视觉认可仍单独验收。
