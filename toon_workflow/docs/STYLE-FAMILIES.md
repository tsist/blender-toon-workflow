# CEL 风格家族使用说明（0.44.1 开发候选）

CEL 家族把材质色阶、显式高光／边缘光设置和完整描边组织到同一个三渲二工作台。材质参数仍在「CEL 配方与显式分配」区编辑；完整线模板仍在「完整描边模板与角色绑定」区绑定；家族区负责共同预检、应用与核验。

**0.41 当前只实现 CEL 家族。** `GAME_REFLECT` 表面或保留彩色头脸的配方，都不代表完整 GAME／MANGA 已实现。家族覆盖的是明确绑定的对象，不能由一次应用成功推出全场景、全身、未见角色或所有灯光已经通过。

本说明根据本批 `candidate` 中的 `style_family.py`、`style_family_ui.py` 及已有 CORE／UI／COLD 记录编写。最终包身份、正式渲染和美术采用范围由本批最终交付记录补充。

## 1. 从已有工程开始

在工作副本中保留可恢复的原工程，先确定要处理的对象、机位、帧和主光。当前已满意的 SDF、鼻嘴线、头发固定影与高光，可直接作为家族的保留基础。

1. 在 CEL 组合配方区准备已有材质角色与实际槽绑定。复杂头脸、眼部、头发等选择「保留原材质」；允许修改的普通表面选择 `SURFACE`。
2. 在家族区填写名称，选择描边组件，然后点击「从当前配方建立 CEL 家族」。这会留存旧 CEL 作者记录，以同一批真实对象／材质槽建立新的家族作者；原材质和描边不会在这一步被替换。
3. 在 CEL 组合配方区调整各材质角色的色阶及需要携带的高光／边缘光，并补全目标绑定。家族单独处理完整描边，因此 CEL 处的描边处理保持「保留现有描边」，简化的 CEL 线角色为空。

若当前家族已有应用回执，先核验现状，再点「留存家族记录并继续作者」，然后从当前配方建立新的家族。留存记录会保持当前原生效果；它不是恢复旧外观的操作。

## 2. 绑定对象的全部已用材质槽

家族要求：**每个已纳入家族的 Mesh，其所有实际被面使用的材质槽都必须显式绑定。** 不能只绑定当前活动槽，也不能用未被面使用的空槽补数。

例如，同一皮肤材质同时出现在槽 0 和槽 6，且两槽都有面使用时，应分别绑定这两个槽。它们可以共用一个 `PRESERVE` 角色；这不意味着需要复制材质。其它眼部、嘴部或鼻片槽也须按实际用途分别纳入保留。

只处理部分对象是允许的；尚未绑定的其它场景对象不自动加入家族。但家族文档中已经定义的每个材质角色都须有实际绑定，未使用的角色应明确移除或补齐目标。预检报告的覆盖范围仅表示这些显式目标与已用槽，不代表全场景覆盖。

## 3. 选择描边组件

| 选择 | 适合情况 | 实际行为与边界 |
|---|---|---|
| 「保留当前完整描边」／`PRESERVE` | 已有满意的原始描边、局部顶点绘制或 INDEX 控制 | 保持当前完整原生描边；它是该工程的本地基础，不运输 INDEX 数据或自动适配另一角色。 |
| 「使用完整描边模板」／`TEMPLATE` | 已有合格的自主静态模板，并准备逐角色绑定 | 使用完整模板整体替换描边，留存旧作者记录；不使用 CEL 配方中的简化线宽／线色角色。 |

使用 `TEMPLATE` 时：

1. 在完整描边模板区导入模板，逐项绑定对象、材质、集合及所需线色来源。图像／节点来源要完成明确确认；UV 必须适配目标的实际表面。
2. 选择「替换描边并留存旧记录」，同名冲突选择「停止并报告」。家族不执行追加模式。
3. 先建立所需受管表面，再将模板材质角色绑定到这些实际 Material。当前家族不允许一边创建／替换 Material、一边猜测完整模板应改绑到哪个新 Material；预检会拒绝这种组合。

保留原 INDEX 绘制的工程可继续使用 `PRESERVE`。不能为了让模板导出通过而删除原绘制、锐边或其它线条控制，也不能把家族 JSON 当作原 INDEX 的便携运输格式。

## 4. 保护头脸，并同步普通材质的修饰方向

面部 SDF、头部／局部法向读者、眼部半透明叠色、头发 HM 与固定影等已有专用作者，应通过 `PRESERVE` 纳入家族。眼部半透明叠色层会明确拒绝被家族表面替换。家族在应用前后核对已有 SDF、头部、眼层和头发状态；不能用通用 CEL 表面覆盖这些依赖来凑统一颜色。

普通材质需要随家族携带高光／边缘光时，在对应 `SURFACE` 角色启用该项。它仍受现有静态、几何法向 BLINN 等资格限制，不会隐式替换头发光带或已有动画。

选择当前场景中的明确 Sun，点击「读取所选 Sun 的修饰方向」，可把当前世界方向写入所有显式携带修饰的 `SURFACE` 角色。这个操作不移动灯、不改变 SDF，也不设置自动跟灯。**换灯或转动主光后，需要在新的作者记录中重新读取快照。** 已应用回执不会被该按钮静默改写。

## 5. 预检、应用与实际看图

点击「预检家族覆盖与状态」，先处理缺槽、未绑定角色、身份变化、无效受管读者或未确认线色来源等问题。`ready` 只表示当前数据可执行，不是美术通过。

点击「应用 CEL 家族」后，系统依次处理已有材质／修饰和所选描边组件，并建立家族及底层作者回执。应用中失败会尝试回退本次变化；若回退不完整，会明确报告，不能将部分产物视作成功。

应用后再次点击预检，或重复点击应用，只核验当前文档、绑定和原生状态。已有手改时会保留修改并报告冲突，不强行覆盖。若在家族待应用期间单独应用了 CEL 配方，也需先留存并明确建立新的家族作者，不能借旧回执绕过绑定身份检查。

最后必须在目标引擎实际看完整材质、Combined 和白底描边，确认鼻嘴线、眼神、面影、头发光影与衣物／道具／背景协调。色阶更平、预检成功、槽数齐全或回执一致，都不能单独代替这一步。概览机位和脸部特写可以分别判断；概览容纳了对象，不等于确认遮挡、细节或完整角色造型。

## 6. 遇到“CEL 会改变材质线色来源”时

当前原生描边若已把某 Material 作为显式线色来源，CEL **创建／替换该 Material** 仍会在预检阶段被拒绝。对已有受管 Material 的同模式参数更新，0.44.1 按实际来源区分：该材质的所有相关策略都是 `AUTHOR_RGB` 时可以更新，固定线色、策略顺序及混色量保持原样；只要存在一条 `NODE_RGBA` 或 `UV_IMAGE`，仍会拒绝。无效所有权、材质身份变化及后续手改继续按原规则拒绝。

固定线色来自作者独立颜色，不读取该材质的色表；因此保留固定线色并修改表面，不需要先移除或重装描边。这不表示线色会自动跟随新材质颜色。需要联动时须显式重作者线色，并在完整画面上检查。

先判断该材质是否确实需要修改：

- 只需沿用现有效果时，将它纳入 `PRESERVE`。
- 同一已有受管材质只使用固定作者线色时，可留存家族记录、从当前配方建立新家族，再修改对应 `SURFACE` 色表并预检／应用。原描边保留；本会话回退及冷开核验规则不变。
- 确需重新组织表面时，先留存当前描边作者记录，明确处理该材质的线色策略，再应用表面变化，随后把线色来源显式绑定到实际目标并重新核验。新 Material 不能靠同名充当旧绑定。

不要通过改材质名、删原顶点绘制、伪造回执或关闭身份检查来跳过这项保护。重新绑定之后，还要重新看实际线色与材质的配合。

## 7. 回退、保存重开与继续编辑

「回退本会话家族应用」只对当前会话中由家族保存的运行时事务有效，并要求应用后没有其它原生修改。若已有后续作者变化，回退会停止以保护这些变化。

保存重开后，家族与底层 CEL 回执可核验当前状态，但运行时回退令牌不会恢复。此时回退按钮不可用，应从事先保留的原工程恢复。历史 Text 记录不自动重建旧绑定，也不是一份完整原工程备份。

要在当前效果上继续修改，先点「留存家族记录并继续作者」，再从当前配方建立新家族。旧效果会保留为新作者的起点，新的绑定与修改需重新预检和看图。

## 8. 导出与在其它工程复用

家族 JSON 保存 CEL 设置、角色及所选描边组件的描述。它不打包原材质着色器、贴图文件、UV、INDEX 绘制、模型、绑定或角色动画。`PRESERVE` 模式尤其依赖目标工程已有的完整描边基础，不能据导出成功称整角色可便携复刻。

导出必须使用新的 JSON 路径，已有文件不会被覆盖。导入需要目标 Scene 的 CEL 作者区尚无角色、绑定和回执；准备导入时，先不要在该目标 Scene 点击新建 CEL 配方。已有作者应先留存，在具备空作者区的目标工作副本中导入；只留存家族记录不会清空底层 CEL 作者区。`TEMPLATE` 导入还要求当前完整线模板区为空。导入后所有材质槽、模板角色和线色来源都需显式重绑，不按同名猜测。

迁移后重新检查实际消费 UV、左右镜像、材质共享者及原生读者状态，再进行目标机位的完整渲染。保留头脸表示保护它们的现有结构，不表示它们已经符合另一风格；完整 GAME／MANGA、跨角色和全场景仍需独立开发及验收。
