# 环绕光照与多机位快速预览（0.44.2）

在同一三渲二工作台的「环绕光照与多机位快速预览」区，一次安排多个光方向和机位，后台输出带角度标签的合并图。原材质、头发高光、固定阴影、眼层和真实投影均参与；它是风格检查用的完整材质Beauty，不包含新的正式描边Line合成。

## 操作

1. 选择场景的当前相机，点击「读取当前源」，核对头部方向参考与唯一白Sun。光向按真实头部参考的右/前/上轴计算，不直接套用灯光Euler数值。
2. 选9/16/36/64格环绕光，或16格「4光向×4机位」。自定义可分别填写光方位/高低、机位方位/高低角表；同方向的纯顶/底重复yaw会去重。保持当前机位时，机位角表不参与。
3. 设置单格像素、采样、每页格数和输出父目录，点击「后台生成预览」。系统为本次工作保存独立副本，原界面继续可编辑。源文件和原Scene不被改存。
4. 「刷新进度」查看完成数，「打开图集」查看已生成页面。申请取消后当前单格结束再停，已完成结果保留。

每次最多256张独立渲染，单页可选9/16/36/64格，超页自动分页；这是当前资源预算，不是全光角质量保证。常规检查可从256px/16samples开始，重点细节回到原交付分辨率和采样复验；不能把小图通过代替鼻眼、发束和像素线宽检查。

高低角−90°是头部正下方，+90°为正上方。方位0°为头部前方，正角向头部右侧。SOURCE保当前镜头；ORBIT保镜头参数而临时环绕指定焦点。读已有静态时刻的镜头动作不等于制作动作；支持与限制以实际恢复报告为准，不通过删除Action/驱动来绕过冲突。

插件不自动隐藏室内墙壁或人物自身遮挡。全暗时先判断场景挡光；需要棚拍对照时另建明确的场景显隐变体，不以关阴影来签材质质量。背景合成只影响图像显示，不改变场景照明。

## 输出与恢复

每个任务独占目录，包含snapshot、request/submission、进度job、preview/REPORT.json、frames下的线性EXR与PNG，以及sheet图集。图集直接拼接已作一次源色彩变换的PNG字节，不再次套用色彩变换。完整角度在JSON，图上标签只保留便于扫描的数值。

每格记录真实RENDER前后相机/灯/头部基准、头发方向字段样本与面部门控；每批前后核原材质/UV/图像绑定。失败与取消均保留partial和恢复检查，不能把已存在的图文件冒充成功。本功能不更改原UV、贴图、rig或动画数据；实际支持范围由对应交付与测试报告限定。

Python入口位于同一个插件的`omni_preview`：`preset/normalize/run/submit/status/request_cancel`。`run`用于受控后台同步任务，交互界面用`submit`隔离快照。不要在用户活动GUI里直接运行长同步渲染。

## 0.44.2 校验性能

本版优化贴图数据的有限性／范围检查，保持同一像素缓冲、通道、哈希、min/max及错误语义；前后实际RENDER见证、眼层处理和恢复检查均保留，不减少采样、不缓存跨pass图像。全RGBA须有限，仅指定R/G/B通道要求在0–1内，不能误把其它有限数据通道也限制到该范围。

性能比较先计真实调用区间，父子inclusive时间不能相加，首次启动与稳态逐格耗时分开看。当前爱音的同源三光角256px／16samples前后完整EXR、PNG及见证逐值一致；具体单次A/B耗时与适用范围读`work/audit/<batch>/`。它不是所有角色、九宫格或其它机器的固定加速比，也不代替正式Line／Combined验收。原安装包及其执行pin继续保留，不改签旧报告。
