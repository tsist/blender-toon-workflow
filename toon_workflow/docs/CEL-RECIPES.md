# 静态 CEL 配方与组合配方

CEL 配方在同一个三渲二工作台中组织表面与二维描边。格式为 toon-cel-recipe.v1；它与材质参数库、Pencil style_file 是不同文件。文件携带角色设置，不携带场景对象绑定。本批已验证核心事务、真实角色创建、保存重开和有限联合输出；具体包与资格见审计交付。

在工作副本的「CEL 配方与显式分配」中创建配方。每个材质角色选择 PRESERVE 或 SURFACE。先选具体对象和实际使用的材质槽，填写已有角色名，再点击绑定活动材质槽；描边角色同样逐对象显式绑定。应用前预检所有绑定，再执行表面和描边事务。场景不受选择名称猜测或自动整角色换材质影响。

脸部 SDF、真实投影读者、头发与睫毛等艺术法向读者只能 PRESERVE。第一版新建表面仅接收简单、静态、不透明材质；已有受管表面只允许同模式参数更新。纹理、透明、共享 DATA Mesh 或动画等不满足首片合同的目标需保留。节点手改、身份改变和失联目标会报告冲突。

首片描边从干净 BASIC 进入完整 Pencil PRESET，按角色消费明确像素宽度与 RGBA 线色，首片仅生成可见边界线，隐藏线和交线保持关闭。已有作者文档、曲线、动画与复杂描边配置须保留。应用成功后，原样重复应用只核验回执；配方、绑定或原生作者内容变化时保留变化并报告冲突。此回执不向 Scene 增加旧受管 Material 指针引用。Blender 撤销支持由作者操作的 UNDO 入口提供。

未应用的槽绑定记录当前会话中的实际材质身份，同名新材质不能替代原绑定。跨进程打开尚未应用的绑定时，先移除并明确重新绑定活动槽；已应用回执可保存重开核验。回滚只清理本次明确创建的 Text，后续作者变化会被保留。

JSON 导出使用新文件，已有目标不覆盖；导入后须重新绑定场景对象。当前 schema 的 revision 是配方内容版本，尚无未来 schema 的自动迁移承诺。

## 携带高光的组合配方（0.34）

在同一面板选择「新建 CEL 组合配方」，或导入组合配方 JSON。旧「新建 CEL 配方」继续创建 v1；旧文档与回执不自动迁移。组合格式为 toon-cel-recipe.v2，仍只携带角色设置；SURFACE 角色可选择「携带高光与边缘光」，PRESERVE 角色不能添加这层。

已有配方的工程可在工作副本选择「保留当前配方并新建组合配方」：先将旧文档、绑定描述和原回执留在带保留标记的 Text 中，再清空当前界面绑定。原材质和描边不变，新配方须重新绑定。归档是历史记录，可能早于后续原生编辑；不能据此自动恢复对象绑定或宣称旧回执仍有效。原工程仍是完整恢复入口。

高光设置包含强度、颜色、阈值、过渡，边缘光包含强度、颜色、指数与偏移，另有明确世界光向。光向是静态艺术快照，换灯后须显式更新；此配方不携带灯光、UV图像、SDF、HM、镜头方案或原生Action。未指定高光时保留已有合法效果；指定时仅新建或更新静态、几何法向、BLINN高光。已有动画、头部光带或艺术法向层须保留，不隐式切换模式或删除。

应用前明确选择「描边处理」：

- 「从基础描边初始化」沿用旧干净 BASIC 首次进入 PRESET 的规则。复杂作者输入仍会拒绝。
- 「保留现有描边」完整保留当前 Pencil 作者。配方中的所有描边角色均不应用，并在结果中明确报告；不能据此声称迁移了复杂 PRESET。

描边策略是当前场景的应用选择，不写入便携文档。材质槽和描边对象仍需显式绑定；未绑定角色会报告。高光先经过全部预检，再按表面、高光、描边顺序应用；失败倒序恢复。组合回执额外核验实际高光与描边策略，手改或换策略后保留变化并报告冲突。需要继续编辑时在新工作副本显式开展新作者操作，不改回执冒充原样。

这是静态组合框架；独立参数动画、复杂 PRESET 增量模板、三套完整风格、复杂透明表面、水烟、Cycles 与完整 P5/P5-V/R4/P6–P9 仍按母任务推进。脸部 SDF 继续作为主路线，配方保留材质不等于已经通过整脸艺术验收。

本批证据：work/audit/<batch>/ 。验收结论以本批最终 DELIVERY 与实际运行报告为准。

0.34组合首片证据：work/audit/<batch>/ 。实际角色与换槽派生工程分别记录；派生工程不作为未见角色的艺术证明。

## 可选明暗过渡（0.49）

组合配方v2的SURFACE角色可携带boundary完整宽度，与finish并存；省略保留原合法层。操作、零宽度、窗口范围、事务与正式RENDER见证见[CEL-BAND-BOUNDARY](CEL-BAND-BOUNDARY.md)。材质参数库不运输此层，旧v1不扩字段。
