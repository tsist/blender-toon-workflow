## 前发关键影形摘要

用途：在固定角色、姿态、相机与实际发束轮廓上，为头部局部 45°、仰角 30°的受光设计清楚的二值影形。

摘要要求：锁定现有前发的外轮廓、刘海分缝、左右位置及发束关系；把明暗组织成连贯、有节奏的块面和必要尖收，减少法向硬阈值带来的细碎斑块。白色表达亮面，黑色表达影面；不要把肤色、月牙高光或 B 固定暗纹重新画成另一套 SDF 细节。脸、眼和其它非目标只作定位参考，不能借制作影形改变它们。

该摘要支持重新提出同类艺术候选，不保证再次生成同样的轮廓或像素。任何新图仍须重新验证实际模型落点、二值分类及最终完整材质。

## 后发关键影形摘要

用途：在有效背面投影上，为头部局部 225°、仰角 30°的受光设计后发块面。

摘要要求：保留后发长度、外轮廓、原有分束和发梢走向，按长发的分组设计连贯明暗，避免散碎噪点或无依据的整头横条。黑白语义与前发相同；方向以真实头部局部坐标为准，不能用画面左右替代角色左右。只处理动态明暗目标，不新增第二套固定高光，不重画原 B 固定影。

## 从艺术图到真实数据的边界

生图原件保持不变。当前回填按原 R 通道的明确分类取候选：`R <= .15` 为影、`R >= .85` 为亮，灰色不确定区域保留初始值。该阈值只是本批解释这两张图的作者选择，不是 SDF 通用默认。

[UV-AUTHOR-TRANSFER.json](<work/audit/<batch>/>) 记录真实 RENDER 三角形与近裁剪范围下的可见表面对应，然后回填已有 `ToonHairHighlightUVFit`。前发当前改变 4929 个 texel、后发 6878 个；这些是本例数据变化量，不是质量得分。隐藏面、未可靠分类的表面与其它方向仍是明确的初始候选。

完整八方向 atlas 的制作由 `hair_sdf_authoring.compile_plan` 与 `hair_sdf_compile.compile_fields` 完成：二值 key／coverage／完整 UV 描述 → 分量内距离场 → 两张 RGBA EXR → 实际重载与每 key 分类重建。数学编码及数据格式是自主编译步骤；不是让生图输出直接充当可信数值场，也不通过改原 UV 来迁就生成图。

初批独立美术设计集中于前发45°和后发225°的可见域；后续补稿见下节。未作者方向及隐藏表面不因“八个通道都有数据”而获得完整美术资格。正式角色看图、公共 Combined／Line 和冷开保护由主线程在最终交付记录中签署，本文件不预签。
