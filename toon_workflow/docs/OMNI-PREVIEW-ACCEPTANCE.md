# 环绕光照与多机位预览：操作与已验范围

适用：统一三渲二插件 0.43 开发候选，Blender 5.2.1 LTS；核验日期：2026-11-13。入口为 3D 视图侧栏「三渲二」→「三渲二工作台」→「环绕光照与多机位预览」，无需另装预览插件。

## 使用

1. 在 Object 模式下确定当前 Scene 相机，点击「读取当前源」，核对「头部方向参考」「单一 Sun」「当前源相机」。使用 EEVEE、sRGB 显示设备、单一白色 Sun 与明确的零强度 World；Sun 保持原生阴影开启。预览保留原材质、头发高光与固定阴影、眼层及环境/角色自身的真实遮挡，不自动隐藏墙壁或关阴影。
2. 选择 9/16/36/64 格环绕光或 16 格「4 光向×4 机位」。SOURCE「保留当前机位」只环绕灯光，读取当前帧的真实相机；ORBIT「环绕头部参考」保留镜头参数，按角表临时环绕参考焦点，可设置距离及焦点偏移，距离 0 沿用源相机到焦点的距离。
3. 自定义四张列表分别为「光方位角」「光高低角」「机位方位角」「机位高低角」，接受 `0,90,180,270`、中文逗号或 JSON 数组。SOURCE 不使用机位列表；ORBIT 将去重后的光方向与机位方向组合。单页可选 9/16/36/64 格，超页自动分页；总预算为最多 256 个实际组合，超限明确拒绝。
4. 设置单格像素、采样和已存在的「输出父目录」，点击「后台生成预览」。本次任务保存独立副本，在隔离后台进程执行，当前界面可以继续编辑。「刷新进度」读取完成数；选择「图集页码」后「打开图集」。申请取消会在当前单格结束后停止，保留已完成帧与可生成的部分图集。

方向以参考物体 **+X 为右、−Y 为前、up=cross(forward,right)** 计算：方位 0° 为前，正角转向右；高低角 −90° 为正下方、+90° 为正上方。纯顶/底的多个方位代表同一方向，会分别在灯光和机位方向中去重；接近但不相同的普通方向保留。完整角度写入 JSON，图中文字为四位有效数值，过长标签限制在本格内。

## 输出、保护与限制

任务目录为 `<输出父目录>/toon-omni-<独立编号>/`：`snapshot.blend` 为快照，`request.json`/`submission.json` 记录请求与宿主检查，`job.json` 记录进度，`preview/REPORT.json` 记录每格见证及恢复结果；`preview/frames/` 保存线性 EXR 与显示 PNG，`preview/sheet-*.png` 为分页图集。图集直接拼接已经过源场景显示变换的 PNG 字节，避免第二次色彩变换。

此处输出为原生完整材质 **Beauty**，暂不含正式 Pencil Line/Combined 合成。每格检查实际 RENDER 相机、灯光、参考及方向字段样本；批次前后核对受管材质/UV/图像绑定。快照使用 copy 模式，不改存原文件；外部依赖内容变化会报失败。失败和取消仍执行逐项恢复并留报告；应同时看任务终态与 `restoration`，不能仅凭图文件存在判断通过。

当前拒绝相机父级/约束、相机 driver、有效 NLA 或 tweak 冲突，以及带有效动画的 Sun。已有相机 Action 在 SOURCE 保持绑定；ORBIT 仅在后台临时解除绑定，最后恢复同一 Action/slot，并检查全部曲线数据，不删除或重建动画容器。空动画容器可以保留。单项恢复异常不会阻止其他恢复，失败项写入报告；不承诺未经验证的约束/动画组合。

新建 Scene 可能返回空的线性色彩空间枚举；Blender 5.2.1 原生 RNA 无法在改为 EXR 后精确还原该状态。遇到此提示，预览会在建任务目录、保存快照或改场景前拒绝。请在「输出属性」中切换 OpenEXR，明确选择有效的线性色彩空间（如 Linear Rec.709），再按需要恢复输出格式并提交；插件不会静默初始化用户场景。
