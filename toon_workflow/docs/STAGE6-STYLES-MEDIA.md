# 0.50：三风格家族、漫画分区与原生媒体操作

本文用于在已有角色、道具和镜头上选择制作路线。适用本批 Blender 5.2.1 LTS / `9e2066aef7ef`；0.50 为同一工作台的开发增量。旧默认、已有 v1 家族和原不透明联合渲染不会自动迁移。

当前资格：已通过本机技术小样、真实 RNA/算子事务及部分独立冷读；完整作品、最终精确包的公共 run / inspect / recover 与美术采用仍在验收。本文说明如何操作，不代表所有列出的组合已经获得作品资格。

## 先选你要的结果

| 用途 | 选择与主要效果 |
|---|---|
| 衣物、道具需要清楚的明暗色块 | 新建 v2 的 CEL：普通表面使用硬边色阶，保留已有色表和修饰。 |
| 希望普通部件明暗过渡柔和一些 | 新建 v2 的 GAME：给普通 CEL3 / reflect 角色设置合法过渡宽度；按部件调节，已有原生反射和单份高光/边缘光继续使用。 |
| 整张角色镜头需要黑白网点、排线，并区分主体与背景 | 新建 v2 的 MANGA，或单独使用“整镜头风格附加图”的 MANGA / 主体背景分区。原材质保留，另输出 Look。 |
| 镜头包含玻璃、水、烟、半透明薄片或自发光 | 在已有媒体表面基础上启用“原生媒体与艺术线输出”，选择保留艺术线叠层或只看原生 Beauty。 |

家族名称不会自动重做头脸。已有 SDF、原 UV/绘制、眼层、头发固定影与高光等专用结构，应作为明确的保留基础；换风格以后仍须检查实际脸部与整镜头。

## 建立、复用和回退家族

入口在“三渲二工作台”的风格家族区，材质角色与槽位在“CEL 组合配方”区编辑。

1. 先把工程另存为工作副本，确认目标相机、帧和主光。为需要处理的对象明确绑定实际材质槽；目标对象的全部已用槽都要有明确角色。需要保留的槽设为 PRESERVE，普通可替换表面才设为 SURFACE。
2. 老按钮“从当前配方建立 CEL 家族”继续建立 `toon-style-family.v1`。需要新机制时，明确选择 CEL / GAME / MANGA，再点“新建三风格家族 v2”；这会建立 `toon-style-family.v2`，不会悄悄升级旧文档。
3. 选择“保留当前完整描边”，沿用本工程的完整描边与 INDEX 作者；需要可运输的完整模板时，先在完整描边模板区导入并明确绑定角色和线色来源，再选择模板。家族模板要求整体替换、遇到同名冲突停止。
4. 点“预检家族覆盖与状态”，修正缺槽、共享或身份冲突后再应用。当前共用按钮仍可能显示“应用 CEL 家族”，实际机制以已建立的 v1/v2 文档为准。应用后先看整镜头，再看脸、衣物、金属反射和线色。
5. 导出到一个不存在的绝对 JSON 路径。文件携带角色、设置和所选描边描述，不运输模型、原材质节点、贴图、UV、INDEX 绘制、绑定或动画。
6. 另一个输入中导入时，需要空的 CEL 作者区；不要提前新建一份配方占住该区。若用完整描边模板，其作者区也须为空。导入以后重新选择真实对象、实际槽和模板来源，不能靠同名自动匹配。
7. 本会话的“回退本会话家族应用”只恢复本次事务，而且应用后没有其它作者修改才会执行。已有修改会被保护并报告冲突。保存重开可检查现状与绑定，运行时回退令牌不会恢复；要回到原状态，应打开事先保存的原工程。

继续制作前可点“留存家族记录并继续作者”，保留当前原生效果再建立下一次作者记录。历史 Text 记录便于追溯，不是原工程备份。

旧 0.48 模板已有真实槽位混用与 Camera ID 覆盖能力：先恢复绑定组件、切换实际渲染相机，再明确应用模板。导入后机位同样要重新绑定。它没有自动换镜头 handler，也不会自动改变本节的整镜头 MANGA Look；旧模板技术证据不代签新角色的效果。

## MANGA：让主体和背景各自成立

有两条入口：

- **家族路线**：建立 MANGA v2 时，在“背景材质角色”明确填配方角色，以逗号分隔；没有背景目标时填 `[]`。应用时由这些角色的真实槽绑定确定背景对象。角色和对象数量不必一一对应；同一对象的全部已用槽必须同属主体或背景，跨区对象应先明确拆分。
- **单独 Look 路线**：在“整镜头风格附加图”选择 MANGA，再选择“主体 / 背景”。用活动网格添加按钮、对象选择框和移除按钮维护背景列表；保存的是实际 Object 引用。未列入的对象属于主体，不按名称、颜色或空间位置猜测背景。

默认仍是 UNIFORM“统一”。OFF 不产生 Look；SEPARATE 才启用两组设置。两区可分别设纸色、墨色、曝光、中调、纸墨阈值、网点/排线间距和角度、像素偏移与网点采样（2或4）；背景选 OFF 可以保留背景原色。前景另有原描边墨色强度。网点是屏幕图案，不随曲面弯曲；按亮度生成的墨色不能区分深色涂装与投影阴影。

单独调 Scene Look 不会同步修改已经保存的家族 JSON。家族应用后再直接调 Scene Look，会使旧家族回执停止覆盖。试调确定以后，若要把参数作为可复用家族运输，应把确认的完整前景/背景设置写入 v2 家族 JSON 的 `look`，在空作者工作副本重新导入、绑定并应用；不要把旧回执当成新的采用记录。

分区先在每个共同采样位置取得同次原生 Beauty 和背景 coverage，累计各区的预乘颜色/Alpha，再分别完成非线性漫画处理。这样主体和背景边缘不会先混成一种颜色、再错误套用网点。最终 Look 保留原 Combined Alpha；原 Beauty、Line、Interaction、Combined 继续独立保存。图案在完整画幅处理后裁切，改变裁切范围时保持同一像素原点。

新分区小样通过不等于实际眼层和裁切已验。旧二次渲染 mask 探针误差约0.01112仍保留 failed，2e-4门槛没有放宽。

## 五类媒体：先做好原生 Beauty，再决定线怎么参与

活动槽的“表面类型”提供已有组件：半透明薄片 ALPHA_SHEET、玻璃 GLASS、水面 WATER、烟雾 SMOKE、自发光 EMISSION。选择类型、检查参数后，只向明确活动槽应用；保留其余槽及原数据。也可以沿用已经制作好的原生媒体材质。

这些对象的外观由原生 EEVEE 渲染：

- 薄片用透明度控制表面。
- 玻璃使用原生透射及明确的厚度/薄壁设置。
- 水组件提供表面波纹与透射；不自动制作岸线、泡沫或流体。
- 烟组件是封闭几何中的静态程序体积；不等于烟流模拟。
- 自发光提供原生发光表面；辉光等画面效果另按实际场景决定。

在同一工作台启用“原生媒体与艺术线输出”，使用本 Scene 的真实本地 Mesh / Volume 对象引用维护媒体列表，不能用文字名称代替绑定，也不能重复绑定。选错对象会影响 Line 的源与遮挡，先检查列表再输出。

| 艺术线参与 | 结果 |
|---|---|
| OVERLAY 艺术叠层 | 原生 Beauty 保留媒体；采集艺术 Line 时暂时隐藏列表内的媒体对象，使它们不生成线，也不作为不透明遮挡。完成后恢复对象状态，再把处理后的整层线叠到 Beauty。 |
| EXCLUDE 排除艺术线 | 不输出可见艺术线，结果以原生 Beauty 为准。不是“只排除列表中媒体自己的线”。 |

OVERLAY 适合希望透过玻璃仍清楚读到轮廓、或有意把漫画线放在烟雾前面的画面。它是一种明确的美术选择：线不会沿玻璃折射路径弯曲，也不随体积透射衰减。不适合拿来证明真实玻璃、水下或烟中的线传播。

关闭此功能会回到原有不透明/受管眼层联合合同；没有取消旧保护来强行接收媒体。启用媒体时，Beauty 使用原生 AA、原生相机景深及运动模糊；它与单独采集的 Line 不具有旧相关四层的重建语义。媒体路径保留 Beauty、Line、OpticalLine、Combined。

**当前不支持非空主体/背景分区与媒体路径同时输出。** 可以关闭 Look、使用统一 MANGA，或明确使用没有背景对象的分区（按前景统一处理）；不能把非空背景列表静默忽略后声称分区通过。媒体原生眼层也不冒称与旧解析眼层逐像素等价。

## 艺术线的景深与运动模糊

这些控制作用于一整层线：

- SHARP：保持原线。
- DEFOCUS：使用统一艺术深度、焦距距离与光圈；最大模糊像素只限制 Defocus。
- VECTOR：使用明确的四通道原生像素速度、快门和采样数。
- BOTH：先运动模糊，再景深。

它们不会自动读取每个角色、相机或物体的真实运动，也不会把各条线分配到不同场景深度。四通道速度按 Blender Vector Blur 约定传入；先用可辨认的运动方向检查结果，不能仅凭图变模糊便认定方向正确。调原生相机景深/运动模糊会影响 Beauty；艺术线的参数需要另行匹配，原生参数不会自动同步为线层的真实光学运动。

检查时至少对照清晰版、处理版和最终叠加版，关注线与眼睛的位置、模糊方向、透明边缘和物体前后关系。当前技术回执只证明像素处理、叠加公式与恢复，没有代签这些美术判断。

## 本轮可复用的制作方法

- **先保护实际消费的 UV。** 换角色或导入模板时，先检查 UV 层名、左右镜像、材质共享和消费节点。头脸的 UV、paint、Sharp、SDF/眼层/头发输入是原作品约束；不要为了统一模板重新铺图。新输入必须实际重绑并检查。
- **非线性效果在正确分区后处理。** 预乘颜色与 coverage 先在共同采样中对应，分别 resolve，再做网点/排线；最终平均 mask 乘已经混色的 Beauty 无法恢复两区颜色。
- **原生输出保留源设置。** 本批采用私有 compositor File Output 输出线性 EXR，不修改源工程 ImageSettings 来绕过空颜色空间等原生状态；输出与失败路径均检查源状态恢复。不要把旧版 File Output 的属性写法直接套到5.2.1。
- **有限艺术层用于可控镜头。** 当目标是读得清楚、有意设计的线层位置和模糊，单层 depth/velocity 足够直观；需要真实折射、体积遮挡或逐物体运动时，应另选成熟原生制作路线，不继续堆单层参数假装恢复完整传输。
