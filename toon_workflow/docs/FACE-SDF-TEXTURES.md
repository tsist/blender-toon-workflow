# 专用面部 SDF 贴图（0.21 开发版）

当前制作方向与视觉验收先见[面部SDF制作标准](FACE-SDF-PRODUCTION-STANDARD.md)；本页保留读者与兼容功能合同。真实UV、角度轴、镜像与端点按所用版本核对，不能从其它工具的图像外观猜格式。

面部形体阴影由艺术设计的入影时机纹理控制。图像在 Shader 中逐像素采样，不能将灰图外观当成数学距离证明。头发、睫毛等原法向功能、原 POINT 面影及镜头修形继续在同一个三渲二插件中使用。

在已有明确面影字段和区域权重的对象上，填写皮肤材质槽 JSON 及相同头部参考，新增专用正面 UV。它只增加新层，不覆盖原 UV。投影按原网格参考空间 X/Z，明确区域整面范围归一化到 .05..95；非正面重叠、非刚性嘴型及侧脸遮挡须另行观察。

先显式解绑旧面影材质，再转换专用左右 carrier：新左源全0、新右源全1，并复制原实际区域权重；原 v1 内核的 threshold 因而精确携带侧向混合量。普通任意阈值属性不能反推左右。已有名字拒覆盖，默认强度仍0；转换记录实际 modifier/owner/源属性。

选择专用本地 FILE 或 PACKED 图像，并先明确设为 Non-Color；绑定不会静默更改共享图的色彩空间。支持选R/G/B，Linear/EXTEND。镜像选项适用于已确认对称的专用UV，右向采样 U=1-U；先分别采样左右，再按侧向混合阈值。入影进度为头部相对水平光角绝对值除以π；不能混用按余弦编码的图。当前0.40实际读者硬比较为`lit = T > phase`；正Softness时为`SMOOTHSTEP(phase-Softness, phase+Softness, T)`，没有0/1恒态特殊分支，不能把外部格式的“1永远亮”哨兵直接套入。极端竖直光沿旧field淡出策略。此处2026-11-13按bundle-v004实际face_sdf代码与编译报告纠正旧说明，冻结旧包字节不重签。

`face_sdf.bind(context,image,uv_name,...)` 只绑定活动独占材质的唯一 Emission.Color，保留原来源并可逆解绑。此 ADD 模式只追加压暗，不能清除原来源中已有的碎形体阴影。图像真实像素/源字节、通道、精度、UV、reader和绑定身份分别校验；艺术编辑后须明确重新绑定，不自动接管作者修改。

可选的单 Sun cast sensor 显式把活动材质唯一 Diffuse.Normal 接入受面部 mix/valid 限制的传感器。原生 GN 每帧记录实际 Sun +Z 世界方向，去除所选区普通 N·L 形体变化，而保留原生投影响应；解绑恢复原法向来源。它不关闭 Sun 阴影、不自动改全部材质。多光、复杂光学和任意引擎不由此获资格。共享皮肤材质的颈肩仍必须依区域权重保护。

公共联合渲染另有 `toon-face-sdf-freeze.v1`（实际 loop UV、图像、shader/绑定、常量 carrier）及 `toon-face-sdf-cast-freeze.v1`（世界 Sun 向量字段）见证。旧 geometry SHA 不包含这些数据，旧 POINT 回执不代签纹理资格。

本批生图资产及一手调研见 `work/audit/<batch>//`。实际图为1254²/8bit候选，明确取R，RGB并非严格等值；不宣称它是2048或16bit。完整面部美术、连续表情、多灯/上下光、可见UI及完整P5仍按母WM独立验收。


复用时先读[制作诊断与复用规范](../../skills/blender-toon-workflow/references/production-reuse.md)。此处“独占材质”按真实消费者判断：同一目标对象多个槽可引用同一材质；其它对象使用该材质，或 user_map 发现目标对象/其 Mesh 之外的数据块消费者时，当前绑定拒绝共享修改。区域权重继续限制脸部，不能把允许同对象多槽误解为整张皮肤都获准改变。


## 可选艺术投影接受层（0.26）

同一SDF面板新增独立的静态接受层。先有合法、已绑定的SDF与明确活动材质，再选择独立Non-Color接受图、R/G/B通道和亮面底色，设置黑位/白位后新增。初始强度0保留原上游颜色；白区保留上游，黑区按强度混向明确底色，结果再进入原SDF。它沿用同一SDF UV、区域mix与valid，不新增UV/GN、不重定向Normal、不改Surface。

接受层会抑制选区内全部上游明暗，包括外物接触投影；常量亮面底色可能覆盖原贴图细节。它是明确的美术取舍，不是选择性物理去除self-shadow。黑位默认0、白位默认1，须满足黑位小于白位；实际案例可按图像数据明确调整，不移植历史数值作通用默认。原v1层继续仅静态，拒绝相关原生Action/NLA/driver；头部移动和区域字段仍由原生图求值。

“更新”只改强度、底色和黑白位；换图或通道先移除再新增。“读取”从实际节点回填暂存值。移除精确恢复原SDF的token、Original Color原来源及绑定快照；要解绑SDF须先移除此层。旧0.25无接受层的节点不会自动迁移，既有study原生图也不被自动接管。源图与文件保留，未知共享图像/材质消费者、手改受管图或动画冲突按原样拒绝。

公共联合输出另记录可选toon-face-cast-art-freeze.v1：真实RENDER材质中的完整受管图、设置、图像source/packed/选定通道及RGBA像素身份，冻结后和绘线前重读。通过实际材质、来源节点、输出插槽关联到既有SDF回执，共享其before/copied/frozen UV与区域字段证据。独立inspect核该关联；旧报告没有此键仍按旧合同读取。生命周期is_runtime_data不作为受管图语义签名，不能以此省略节点、插槽、连线和图片数据。

### 显式强度动画（0.27）

新增前勾选“新层启用强度动画”，建立独立v2层。默认仍静态v1，既有层不自动升级。旧v1要使用动画，先读取并保留实际图像、通道和参数，明确移除再以动画模式重绑；原SDF owner/token与来源恢复记录保留。

在所需时刻设置暂存强度后点击“当前时刻插入接受强度关键帧”。仅动画独占ShaderNodeTree内部的一个Value，范围0..1、LINEAR插值、CONSTANT曲线外推；底色、黑白位与外层Material保持静态。合法原生LINEAR编辑可保留；未知路径、共享Action/组、drivers、NLA及非LINEAR拒绝。有曲线时用关键帧改变强度；普通更新可保留当前强度并改静态参数。

移除动画层或换图前，先“解除强度动画并保留Action”：保留当前值，旧Action设fake user。重新插帧建立新Action，不自动重挂旧Action。API与恢复顺序见[接受层作者说明](../../skills/blender-toon-workflow/references/face-cast-art.md)。

新输出freeze.v2附实际RENDER时间、Action及当前曲线，仍可记录静态v1。用同一实际图显式读取evaluated group，冻结后和绘线前保持；独立reader交叉绑定联合时间。旧freeze.v1及旧无该键报告保持读取。JSON自洽不证明真实求值或连续美术质量，须结合真实输出和冷开。

作者API在face_cast_art模块：bind / update / inspect / unbind；snapshot与受限snapshot_frozen供公共冻结。它不增加公共run/edit参数。实际资格以toon-sdf-cast-art-integration-20261110-v001最终DELIVERY为准；开发代码、UI注册或技术夹具不代签角色、连续表情、多灯或完整艺术验收。

## 同一脸部对象上的独立鼻影材质（0.30）

已有鼻影面片须先按真实连通块与材质槽取证，不能因与皮肤共用材质就把它当作普通脸面。可只给明确的鼻影面分配独立、不透明的无镜面材质，用已有正面UV限制浅暖鼻尖标识，再通过同一 `face_sdf.bind` 建立独立Image ID和reader；保留原来的channel、mirror、Shadow Color与Softness。局部鼻标识与大面影是不同层。整片直接染色可能形成过大的泪滴鼻；面片的独立Line也须单独按明确corner R控制，材质变浅不自动去掉边线。这里不把鼻影声明成眼部透明层，也不增加几何或绑定修复。

公共冻结原 `toon-face-sdf-freeze.v1` 保持每对象唯一SDF读者的校验。0.30仅在实际同一对象出现多个读者时使用 `toon-face-sdf-freeze.v2`，逐读者记录真实Material及其非空已用槽，验证冻结前后身份相同、不同材质/reader/owner与不重叠槽。共享对象的读者必须来自同一个face carrier和同一UV，原/实际RENDER载体和UV快照一致；历史创建weight哈希不作为跨读者一致性的替代。v2计数为读者/材质绑定数，两个读者不代表两个脸对象。v1旧回执继续读取、旧重复target仍拒绝；未知版本仍拒绝。

v2在冻结参考与每个绘线采样前复查实际材质槽、reader、绑定及图像，不能用名称相同或JSON自洽代替实际引用。含多SDF材质的候选应配0.30及以上匹配实现，不能用0.29公共出口。限定实证与保留失败从 `work/audit/<batch>/` 恢复；当前不外推为多头、任意多UV、透明贴花或完整风格资格。


## 可选阈值图采样平滑（0.33）

同一SDF面板在绑定新读者时提供采样平滑半径，单位是图像像素/texels，默认0沿用原v1。`face_sdf.bind`与`shader_group`的可选参数`filter_radius_texels`为有限非bool数值0..64；>0明确建立`toon-face-sdf-shader.v2`，不自动升级旧组。半径只在创建/重绑时设置，不能直接改受管组或绑定快照。改变模式/半径需合法解绑重绑；有静态艺术接受层先保图/设置再移除，之后重建，带Action另守动画保留合同。

v2在每侧实际UV上取3×3双线性样本，标准[1,2,1]外积/16正权重，共18个ImageTexture引用；右侧先mirror，再对称偏移。偏移由真实图像宽高把texels换算到UV。只平滑所选R/G/B阈值标量，再按原side混合、phase比较和Softness控制；不模糊最终画面、不改图片字节或原UV。每材质独立Image/reader，未知消费者守卫保留。已有不同采样模式的未绑定组可能仍引用旧Image；切换时可显式重新加载同PNG成独占Image数据块并核内容，旧源保留恢复，不放宽共享或随意清组。

新采样元数据、节点图/签名、图像/尺寸/通道、原/实际RENDER UV与绑定按实际profile核验和冻结，绘线前重新检查。旧v1图/接口/签名/descriptor保持；shader v2是采样变体，和同对象多材质的freeze.v2容器是不同版本维度。新的报告需配支持v2的实现，不能以旧0.32读取新组。

空间过滤可能移动局部等值线、吞小特征或跨UV岛混采，须先核实际UV/图像布局与表面落点，再看完整材质、必要光向和最终Combined。它不把非单调图变成数学SDF，也不替代入影轮廓作者设计、真实发影或抗锯齿。具体原包、参数选择与已验资格从当批DELIVERY读取；不以0.33版本号或默认值签完整风格。


## 关键光角明暗形状编译（0.40）

同一SDF面板可把已按实际消费UV注册、审查过的二值关键光角图编译成新的16位方向阈值图，暂存后仍显式绑定材质；旧图、UV和SDF解码保持。字段、数值语义、保护与验收见[SDF-KEY-AUTHORING](SDF-KEY-AUTHORING.md)。
