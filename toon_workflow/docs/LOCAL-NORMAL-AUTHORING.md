# 头部局部作者法向（0.20开发版）

局部作者方向图为脸、眉睫、头发、眼口等已登记Mesh提供可编辑的着色方向。它与整头配置、原Diffuse连接、二维描边和镜头修形共用母工作台，不需要第二个插件。原椭球模式保留，任何已有文件不会自动改为方向图。

## 使用步骤

1. 在现有「单部件法向与材质连接」中选活动部件。先有一个有效的艺术法向字段与明确头骨参考；原来的局部权重和强度继续决定影响区域。
2. 指定新的作者方向属性名，初始化参考模板。它按**原网格顶点**建立静态参考方向，不捕获当前求值后的表情或蒙皮法向，也不会立即改变现有效果。已有属性不覆盖，共享Mesh先独立复制。
3. 显式启用映射模式。原GN修改器身份、头部成员、参考/权重/强度及已连接的材质读者保留。已有原生输入动画或手改GN会拒绝接管。
4. 进入该部件Edit Mode，明确选中需要修改的顶点，在母工作台设置参考方向和混合量，写入所选。没有选择会拒绝，绝不自动写全头。非所选方向、位置、拓扑、原Mesh法向、形态键和顶点组不改。
5. 需要局部调整影响量时，在同一 Edit Mode 中明确选择顶点，设置「局部权重值」和「权重混合量」并写入。操作只使用当前受管修改器实际绑定的 FLOAT/POINT 权重属性；顶部创建用属性名不决定写入目标。权重乘该部件当前强度，写权重不会启用字段或改变强度。空选择、共享 Mesh、无效/内部/输出别名属性与非有限源值均拒绝。混合量0完成预检与读回，核心不写数据；UI仍需切换对象/编辑模式。权重属性应由该字段专用，共享消费者会看到同一属性变化。
6. 使用真实灯光观察正面、斜侧面及表情。可继续编辑原生属性；方向图通过上游拓扑修改器插值，零向量、缺属性或插值退化会被字段验证拒绝。恢复椭球模式时保留作者属性供以后继续编辑。

一个头部配置中的部件可以混用椭球与作者方向图，仍各自保持独立字段/权重/强度。材质仍需显式绑定；切换模式不重新布线或覆盖作者Normal链接。加入整头不等于自动给所有材质绑定法向。

## 坐标与动画边界

Profile `toon-artistic-normal.v2` 读取 `FLOAT_VECTOR / POINT` 属性。每个向量是在指定参考物局部空间表达的协法向方向：世界方向为 `normalize(B_linear^-T * authored_direction)`，而非再乘目标Object矩阵。参考物包含头骨跟随、旋转和比例；非均匀缩放/剪切按完整逆转置处理。它不是RGB编码、切线Normal贴图或脸部SDF阈值图。

初始化使用 `q=B^-1*A*p_source`，只把原网格顶点映射到参考空间作起点。方向图随头部参考运动；不会自动随独立下颌、嘴型或头发摆动重做真实表面法向。需要这些细节时使用区域权重、椭球模式、作者动画或后续变形传输机制，不将静态模板称作当前Pose捕获。

最终normal/mix/valid仍在原生变形后、镜头修形前求值并逐帧冻结。世界场仅供该时刻着色，不能当跨帧缓存或FBX/glTF导出法向。实际地图名和空间记入回执，并与整头配置中的实际字段检查交叉；旧v1报告不因此取得映射资格。

本增量仍是本地Mesh方向场，不自动产生优秀鼻颊交界，也不处理透明发片、Curve毛发或完整SDF。完整P5三种风格、连续多灯艺术与P9发行仍按母WM推进。

## 标量作者 API

`normal_authoring.write_weight(target, modifier, indices, value, blend=1.0)` 从当前 owned 修改器读取真实绑定，返回 `toon-normal-weight-authoring.v1`、实际属性名和所选原始顶点读回值。只支持本地独占 Mesh 的 Object Mode，显式非空唯一整数索引和有限 [0,1] 标量；不修改作者方向、真实法向、几何、材质、整头配置或全局强度。写入/读回失败会尝试恢复完整原权重；回滚失败明确报错。它不修复已有 NaN/越界权重。方向场仍是静态参考协法向，未增加下颌/发丝变形传输。
