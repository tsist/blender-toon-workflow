# 全方向头发SDF：仰角环与上下极点（0.43候选）

旧`toon-hair-sdf.v1`仍是八方向yaw影形，默认旧调用不迁移。新增显式`toon-hair-sdf.v2`采用三张RGBA浮点图：前两张保存+30°仰角的八个yaw键，第三张R为唯一上极、G为唯一下极，B/A严格为1。它是本项目自主的全方向作者表示，不是厂商公开算法，也不把原HM.G改名为SDF。

## 表示与边界

按真实头部right/forward/up与Sun世界+Z求yaw和elevation；先循环插值八个环键的距离。在e≤30°时按(e+90)/120从下极距离混向环；在e≥30°时按(e−30)/60从环混向上极。全部距离合成后只作一次阈值比较，再与原lit_raw按SDF强度混合。色表与现有R高光继续使用同一个有效lit，原B固定影仍在后乘，不增加第二套高光。

两极各有唯一影形，环权重归零，yaw不再影响结果。v2的valid表示方向求值合法，纯竖光保持1，不再淡回原HM。默认v1继续原极点回退语义。数学保证限C0连续与环/极点插值合同，不声称C1、连续任意光角美术完美或多灯/Cycles支持。

10键给整个方向域定义了结果，但下方30°仍是插值而非独立作者键。若实际图集暴露该区域表达不足，应据证据增加相应作者维度，不能用更硬softness、更多水平键或扩大fallback冒充修复。

## 计划与接入

`toon-hair-sdf-keys.v2`计划保留明确uv/coverage/keys；前8行angle_degrees=0..315、elevation_degrees=30，末两行angle_degrees=0、elevation_degrees=90与−90。二值mask仍白为亮、黑为影，在实际独立UV上编译并重载验证全部RGBA。生成艺术图与数值距离编译分开，实际UV对应、映射唯一性、采样密度分别核验。

现有`hair_sdf_authoring.compile_plan`按schema识别8键/10键。`hair_sdf.attach(..., mode='omni_v2', pole_image=...)`显式接入第三图；旧默认`cyclic_v1`只读两图。更换模式、UV或图像前正式移除旧子域，再零层接入，核对原HM后恢复作者强度。`update`仍只控制strength/softness；禁止改声明/签名绕过变化。

原高光/固定影的UV与新SDF UV分离，消除SDF相关不同表面共UV的冲突；不覆盖旧R/B UV。原raw/RENDER连续三角交叠、退化、间距及实际屏幕密度均需审查，原生unwrap/pack完成不等于无重叠。盘状chart若自由边界自交，可在核验拓扑后使用正权凸边界参数化，再重新pack及独立连续审计，避免逐面切碎来凑零重叠。

## 当前验收口径

先看同机位的环绕光图，再看多机位；包括上/下斜光、两极与附近、背面、接缝、R高光暗区及B固定影重合。原v1冷读、零层/卸载、v2实际RENDER和完整冻结/独立冷开、非目标保护分别记录。固定角度或小夹具通过不能扩大成人物全角艺术通过。实际候选、单包SHA与未通过项以本批DELIVERY为准。

研究依据：MingToon作者文档的左右上下通道与独立UV设计，Epic/Kuro访谈的特殊纵向阴影贴图；只作表示与流程参考，未复制其商业代码/素材或引入运行依赖。精确公式与当前选择见本批研究记录。
