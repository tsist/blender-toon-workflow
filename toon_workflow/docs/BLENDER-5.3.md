# 在 Blender 5.3 中修角色近景

用 Blender 5.3.0 打开旧作品，选择 EEVEE。在 3D 视图的侧栏打开「三渲二」，展开「5.3 主光、发影与统一校色」。先点「另存 5.3 升级工程」，选一个新文件名。需要恢复旧作品时，用 5.2.1 和 0.51.1 插件打开原文件。

1. 切到要修的摄影机，选中脸部网格及对应材质槽。指定太阳灯作为主光，按镜头需要再选副光，点「建立项目灯光与影形控制」。使用现有面部 SDF 的角色应选择原来驱动脸影的主光。
2. 在「活动材质槽」选择「面部」并接入。切换到头发的材质槽，选「发束」，指定美术绘制的亮带遮罩与该发束实际使用的 UV，然后接入。其他需要统一校色的材质可用「校色」。对共用材质，先核对其所有使用者。
3. 在摄影机画面用整体控制调整刘海投影的位置、宽窄和浓淡。修遮眼的一小段时，用「选中局部落点」把作用中心放在眼侧，用「选中局部拖动点」调偏移。局部半径决定附近哪些区域一同移动。如果只需露出上眼睑，选择脸部材质槽，点「为活动脸部槽添加上睑控光」，移动窄区中心，调整半宽、半高和减影量，直到眉下仍有窄影。给相机影形控制打关键帧，拖动时间轴查看过渡。
4. 在「项目色板与明暗」统一调色。通过活动材质槽的锁图标，仅覆盖需要例外的颜色或参数。例如锁发丝亮色后，更改项目暗色和整体明度，检查发色保留与暗面的跟随。CEL、GAME、MANGA 的项目均可沿用这套操作。
5. 审片时保持机位一致，依次只转头、只移主光、再打开蓝色副光。在相同姿态下比较修形前后，检查眼睛是否露出、另一侧轮廓是否稳定，以及亮带是否仍落在画定的发束上。保存并重开副本，再看关键帧、主副光和材质覆盖。

此工作流的制作与实机验收范围为本地 Blender 5.3.0、EEVEE 和可编辑的本地角色材质。具体作品和已验证的输出见迁移交付说明。

已有逐镜头形变的作品需要在相机镜头方案中为新增近景登记原参考物、目标和形变强度。用实际登记的相机审片和提交后台作业，尤其要核对上、下睫毛和眼球的位置。

## 0.52.1 的面部法向

打开已用 0.52.0 接入的工作副本，切到登记相机，选中脸部对象及原皮肤材质槽，在「5.3 主光、发影与统一校色」点「恢复面部艺术法向」。新接入的面部槽会在绑定时处理。若原皮肤材质没有艺术法向来源，继续使用原几何法向。

「面部法向混合」控制主光使用美术绘制的头部方向与原面部投影读者之间的比例。此属性可在 Blender 中打关键帧。爱音近景使用 0.42，原有的眉下窄影另由上睑控光编辑。要检查改动，固定主光并比较正面和转头姿态，再横移主光观察鼻旁灰斑和明暗交界。副光保留独立的受光计算，可在同一帧单独开关，检查暗面的着色。
