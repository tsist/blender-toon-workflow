# 方向阈值面影

0.18.0开发增量，适用于当前已验Blender 5.2.1 LTS的本地不透明Mesh与EEVEE着色工作流。入口位于同一Toon母工作台的面影区，与整头艺术法向、镜头修形及二维描边共用单包。

## 创建与编辑

1. 选中目标Mesh，指定头部参考Object和一盏实际SUN。参考的局部+X表示右侧、-Y表示正面；这里的左右是参考轴定义。
2. 创建缺失属性。默认左右阈值各0.5、区域权重0；已有合法属性保留。三个源图均为FLOAT、POINT、0..1。共享Mesh通过操作入口隔离副本。
3. 创建面影场，初始强度0。左右图表示相应侧光下从亮转暗的光向阈值，较大值延后转暗。权重限定作用区域，与艺术法向权重独立。
4. 在Edit Mode明确选择顶点，用选区写入设置左图、右图或权重；空选会拒绝。编辑值与混合系数均限制0..1。
5. 配置强度、侧切混合及顶光淡出。选中独占的不透明材质，设置阴影颜色上限与柔度，再绑定唯一Emission颜色输入。默认0强度或0权重保持原颜色。
6. 通过检查入口核对配置。需要恢复原材质颜色连接时使用解绑；读者被手改、增加消费者或相关输入动画发生冲突时明确拒绝，不覆盖用户编辑。

## 光向与着色

参考变换先对+X/-Y做Gram–Schmidt正交化，允许非均匀缩放、shear及负行列式，按声明的轴向解释。朝光方向取求值后SUN的+Z。水平光向与正面的夹角除以π得到phase；精确顶光或底光关闭该附加面影。SUN本身的镜像、shear等歧义输入会拒绝。

侧切混合默认0.05，通过水平右分量平滑混合左右图，避免正面瞬间切图；设0时显式硬选。顶光淡出默认0.1，在接近竖直时降低混合。Shader在网格插值后比较threshold和phase：柔度0时threshold大于phase为亮，等值为暗；正柔度时采用居中过渡，等值为50%过渡。

最终颜色为原颜色与逐通道min(原颜色,阴影颜色上限)之间的混合，只会压暗。已有更暗的发影会保留。它不能把原暗面提亮，也不分离投影与自阴影；需先把原生材质和灯光调到合适的基础效果。Surface、Alpha和Normal连接保持原样。

## 原生数据与联合输出

顺序为原生变形→方向阈值面影→艺术法向v1/v2→镜头修形。面影GN只存储threshold、phase、mix、valid四个POINT字段，名称由owner派生；不修改位置或法向。节点完全原生，不新增handler、driver或调度器，保存后可在未注册插件时求值。

联合渲染逐帧在RENDER求值中核对四字段的角色、类型、数量与哈希，要求作者场、复制体及冻结体一致。旧报告缺少面影段时不授予面影资格。源图、参考、SUN、强度与fade参数随回执绑定，仍沿公共CLI作业与父接受路径。

## 当前边界

这是作者控制的方向阈值POINT图，不是自动生成的有符号距离场，也不是完整UV/SDF贴图管线。当前只支持一盏显式SUN；面影不是多灯照明求解器。绑定限独占本地不透明材质与唯一Emission颜色路径；透明发片、Curve、多头、Cycles、导出和连续表情美术尚未由本增量验收。完整三类风格模板、完整P5及后续阶段继续按母WM推进。
